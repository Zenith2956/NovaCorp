# Procédure d'onboarding — nouvel employé

**Catégorie :** Onboarding · **Référence :** RH-PRO-003 · **Version :** 1.4 · Septembre 2026 · **Fichier source :** 03-procedure-onboarding.md

| | |
| --- | --- |
| Destinataires | Managers, service RH, service IT, binômes référents |
| Propriétaire | Service Ressources Humaines — rh@novacorp.fr |
| Plateforme | Le profil est créé automatiquement dans la plateforme RH à la signature du contrat |

## Avant le premier jour (J-5)

Le service RH crée le compte de l'employé dans la plateforme RH NovaCorp : le profil est généré automatiquement, avec le rôle « employé ». L'email de bienvenue, contenant les identifiants provisoires, est envoyé 5 jours avant la prise de poste.

## Le premier jour (J1)

L'arrivée se fait au bureau, jamais en télétravail. Programme de la journée :

- 9h00 — accueil par le manager et visite des locaux (badge remis à cette occasion) ;
- 10h00 — rendez-vous RH : remise du contrat signé, du règlement intérieur et de la convention collective ;
- 11h00 — configuration de l'ordinateur portable avec le service IT ;
- 14h00 — présentation de l'équipe et du binôme référent, désigné pour les 2 premières semaines.

## La première semaine (J2 à J5)

Le binôme référent accompagne le nouvel arrivant : accès aux outils internes, premiers code reviews (pour les équipes techniques), prise en main de la plateforme RH. Toute demande (congés, frais, matériel) se fait exclusivement via la plateforme.

## La fin de la période d'essai

À la fin de la période d'essai (4 mois pour les profils techniques, 3 mois pour les autres), un entretien de mi-parcours est organisé par le manager. Le compte rendu est déposé dans la plateforme RH.
