# Congés exceptionnels et événements familiaux

**Catégorie :** Congés · **Référence :** RH-POL-004 · **Version :** 2.0 · Septembre 2026 · **Fichier source :** 04-conges-exceptionnels.md

| | |
| --- | --- |
| Destinataires | Tous les employés NovaCorp |
| Propriétaire | Service Ressources Humaines — rh@novacorp.fr |
| Plateforme | Type de demande « événement familial » — non décompté du solde de congés |

## Mariage ou PACS du salarié

4 jours ouvrés de congé, à prendre dans la semaine de l'événement. Justificatif : acte de mariage ou attestation de PACS, à déposer dans la plateforme RH après l'événement.

## Naissance ou adoption

3 jours ouvrés, à prendre dans le mois de la naissance ou de l'arrivée de l'enfant. Le congé paternité légal de 25 jours s'y ajoute ; la plateforme RH guide le salarié pour combiner les deux.

## Décès d'un proche

| Lien de parenté | Jours ouvrés accordés |
| --- | --- |
| Conjoint, partenaire PACS, enfant | 5 jours |
| Père, mère, beau-père, belle-mère, frère, sœur | 3 jours |
| Grand-parent | 1 jour |

Aucun justificatif n'est demandé pour un décès : NovaCorp fait confiance à la parole de ses salariés.

## Déménagement

1 jour ouvré par an, sur justificatif simple (facture de déménagement ou bail). Le jour doit être posé via la plateforme, type de demande « événement familial », et non décompté du solde de congés.
