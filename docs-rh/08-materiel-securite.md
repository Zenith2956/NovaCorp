# Matériel informatique et sécurité

| | |
| --- | --- |
| Destinataires | Tous les employés NovaCorp |
| Propriétaire | Service IT — it@novacorp.fr (co-piloté avec les RH) |
| Plateforme | Demandes de matériel via la plateforme RH, type « matériel » |

## Attribution du matériel

Chaque employé reçoit un ordinateur portable (MacBook Pro pour les équipes design, PC Dell pour les autres) configuré par le service IT. Le matériel est prêté : il reste la propriété de NovaCorp et doit être restitué le jour du départ de l'entreprise.

## Perte ou vol

En cas de perte ou de vol, prévenir immédiatement le service IT par téléphone (le poste est effacé à distance dans l'heure) puis déclarer l'incident dans la plateforme RH. Sans déclaration dans les 48 heures, la franchise de 150 € peut être retenue sur la prochaine paie. Le vol avec dépôt de plainte n'entraîne aucune retenue.

## Règles de sécurité

- Mot de passe : gestionnaire de mots de passe fourni par l'entreprise, jamais de note écrite ;
- Aucune donnée client ou RH ne doit être envoyée à un outil IA externe sans validation du service RH (point abordé en formation annuelle) ;
- Badge : obligatoire dans les locaux, signalement d'un badge perdu sous 24 heures.

## Demande de matériel complémentaire

Écran, clavier, casque : la demande se fait sur la plateforme RH, type « matériel », avec validation du manager. Le service IT livre sous 5 jours ouvrés au bureau (jamais à domicile, sauf situation particulière validée par les RH).
